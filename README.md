# Sympathy

  A MediaCore importer plugin for Windows. It lets Adobe Premiere Pro, After Effects and Media Encoder open video
  formats they do not support on their own: AV1, VP9, FFV1, APV, JPEG 2000, CineForm, MKV and WebM with any codec, and
  more. Decoding is done by FFmpeg.

  **Download:** [Sympathy.Setup.exe](https://github.com/balt1kaa/Sympathy/releases/latest/download/Sympathy.Setup.exe).
  Close Premiere Pro, After Effects and Media Encoder, run the installer, start them again.
